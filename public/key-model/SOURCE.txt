The ONNX file is an inference export of checkpoints/openkeyscan2.pt at
the pinned revision. To reproduce it, load that state dict in model.KeyNet
with Nf inferred from conv1.conv.weight.shape[0], put it in eval mode, and
export at opset 17 with input cqt [1, 1, 105, frames] and output logits.
The input's time axis is dynamic. Output classes use the upstream Camelot
order (1A to 12A, then 1B to 12B).
